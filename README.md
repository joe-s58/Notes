# Security Study Notes

Organized notes and cheat sheets from the certifications and courses I'm working through on the path to a Tier 1 SOC analyst role.  Used for Quick Reference.

## Contents
- `/security-plus`: CompTIA Security+ notes by exam domain
- `/cysa-plus`: CompTIA CySA+ notes (starting after Security+)
- `/dfir`: forensics course notes (log analysis, memory, disk, network)
- `/cheat-sheets`: one-page references (Linux terminal, Wireshark filters, Windows event IDs, common ports, ATT&CK tactics)
- `/glossary`: terms and acronyms I keep needing to look up

## How I organize notes
- One file per topic, (example: `network-attacks.md`)
- Each file ends with a short "SOC relevance" section
- Cheat sheets
